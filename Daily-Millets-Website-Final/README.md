# Daily Millets — Final Website

This is a static HTML/CSS/JS website designed to closely match the supplied Daily Millets reference screens while using the real Daily Millets packaging assets.

## Folder structure

Upload the CONTENTS of this folder so that GitHub looks like this:

daily-millets-website/
├── index.html
├── styles.css
├── script.js
└── assets/
    └── (all images)

IMPORTANT: `index.html` must be in the repository root. Do not put it inside another `dailymillets-website` folder.

## Vercel

Framework Preset: Other
Build Command: leave empty
Output Directory: leave empty
Root Directory: leave empty

The site is a normal static website, so no build step is required.

## Features

- Responsive desktop/tablet/mobile layout
- Sticky navigation
- Mobile menu
- Product search
- Product cards and Add to Cart interaction
- Wishlist interaction
- Newsletter form interaction
- Real Daily Millets packaging imagery
- Sections matching the supplied reference: hero, categories, benefits, bestsellers, palm-oil banner, story, customer stories, recipes and footer
